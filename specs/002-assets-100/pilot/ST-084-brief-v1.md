# ST-084 椅子

TASK：T06-PILOT-BRIEF；REQ-002、REQ-015；AC：AS01–AS07、AC15。
本件 brief 已完成編寫；風格母版尚待產品核准，圖片、模型、授權與 QA 均未完成。
分類：生活物件。正式件數仍為 0；不以 brief 或概念圖計數。

## 固定造型與參考圖 prompt

四腳木椅、直立靠背、厚座面；沒有坐人或軟墊，椅腳穩定接地。

> 製作一個供線上沙盤 3D 建模參考的單一「椅子」。精緻微縮公仔、半寫實、柔和霧面樹脂或木質手感，暖色中性、輪廓清楚。完整物件置中，留足邊界，3/4 視角、接近正交、均勻柔光。淺灰背景，無地景、無底座、無文字、標誌、浮水印、景深或多餘配件。固定特徵：四腳木椅、直立靠背、厚座面；沒有坐人或軟墊，椅腳穩定接地。 配色：霧面淺胡桃木。可動要求：無預製動畫；整體路徑位移。 不使用真實人物照片、個案資料、品牌或影視角色。

初次候選 1–3 張；選唯一 canonical reference 後才補正／背／側面，分開檔案。
補圖 prompt：沿用核准圖的比例、配色、部件，只改為指定完整近正交視圖；不新增造型。補圖不一致時人工裁決，不將四格圖直接轉模。

## 建模與動作契約

建議路線：Blender 幾何建模。模型預估高度 0.9 units（工程草案，風格審閱可調）；glTF 2.0 GLB，Y-up，原點在接地中心，單位一致。動作：無預製動畫；整體路徑位移。
可調材質槽：wood。所有物件可移動、旋轉與等比縮放；M/H 預設停止。
目標 triangles ≤ 6000、材質 1–3、主貼圖 1K、傳輸目標 ≤ 2 MB，重點例外 ≤ 5 MB 須另審。
至少一個簡化 LOD；Meshopt、KTX2 需搭配實際 decoder/fallback 載入檢查。

## 加工風險與檢查

主要風險：椅脚交叉黏連、靠背孔洞填滿、座板只有單面。
Blender 工作：底部檢查四脚分離，座面和靠背具厚度；Y=0 對齊四腳底，包圍盒貼合。
每件保存 raw mesh、加工紀錄與 .blend，不能直接發布供應商原始產物。

## 驗收與證據

- AS01 數量與真 3D：本件 assetId 唯一，360 度有實際體積；G1 整批檢查 10 件，正式發布須 100 件。
- AS02 結構品質：六方向與轉台檢查法線、破面、浮件、洞口和薄結構；設計孔洞必須保留。
- AS03 視覺一致性：與核准風格母版比較材質、比例與色彩；產品逐件核准，不預填 PASS。
- AS04 檔案性能：GLB validator 和 loader、面數、LOD、draw calls、貼圖與傳輸 bytes 實測，超標另審。
- AS05 操作：pivot、bounds、點選、移動、旋轉、等比縮放及可調色槽逐件測試；真機 iPad 結果另記。
- AS06 動畫：H 必須 idle/walk/wave，M 必須指定 clip，S 記錄不適用；停止後不得持續位移。
- AS07 來源與安全／AC15：參考圖、prompt、供應商、條款、hash 與加工歷史齊全；不送任何個案資料。
- AS08 發布及縮圖：縮圖由最終 GLB 渲染，版本及 hash 不可覆寫；G1 雖只要求 AS01–AS07，正式 RELEASED 仍須 AS08。

正式 AS 定義以 [素材規格](../spec.md) 為準。QA 尚未執行，不能以這份清單宣稱 PASS。
